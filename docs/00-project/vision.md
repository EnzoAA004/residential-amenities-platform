# Project Vision

## Product statement

Residential Amenities Platform is a private-source, cloud-hosted system for managing residential amenity availability, reservations, payments and administration.

The pilot will serve one building with 10 units (1A through 5B). The first amenity is the SUM (shared multi-purpose room), with optional event resources such as barbecue/grill and swimming pool.

## Problem

The current process can become fragmented across conversations, manual confirmations, payment messages and informal coordination. That makes availability, ownership of a booking, payment status and changes harder to trace.

## Vision

Provide a simple experience for residents of different ages while maintaining a professional backend with auditable booking rules, payment state, administrative control and cloud operations.

## Product principles

1. **Simple for residents.** The interface must not expose internal complexity.
2. **Server-side authority.** Sensitive rules, prices, authorization and payment confirmation live on the backend.
3. **Traceability over deletion.** Financial and booking history should remain auditable.
4. **Configuration over hardcoding.** Prices, time windows and operational rules should be adjustable.
5. **Pilot first, SaaS-ready later.** Avoid unnecessary SaaS complexity in the MVP, but do not couple the domain to a single hard-coded building.
6. **Private source.** Customers use the hosted service; source-code delivery is not part of the standard product.
7. **Operational discipline.** Infrastructure, deployments, costs and architecture decisions are documented and reproducible.

## Success criteria for the pilot

Residents can understand availability, create valid reservations, complete or declare payment, receive clear status feedback, and administrators can manage exceptions without editing the database manually.
