# ADR-005 — Use Angular + Ionic + Capacitor

- **Status:** Accepted
- **Date:** 2026-09-27

## Context

The product needs a responsive web experience and a path to Android/iOS while giving the maintainer experience outside the usual React/React Native approach.

## Decision

Use Angular with Ionic and Capacitor.

## Consequences

- Shared client code across web/mobile use cases.
- Adds Angular/Ionic experience to the portfolio.
- Mobile-specific capabilities still require deliberate platform testing/configuration.
