# Glossary

| Term | Meaning |
| --- | --- |
| SUM | Shared multi-purpose room / common event room. Primary reservable space in the pilot. |
| Amenity / resource | Reservable or attachable common resource such as SUM, pool or barbecue/grill. |
| Unit | Residential unit such as 1A, 1B, ..., 5B. |
| Resident | Authenticated person associated with a building unit. |
| Reservation | Time-bound request/commitment to use one or more resources. |
| Shared leisure | Short SUM booking that can coexist with compatible reservations. |
| Exclusive leisure | Short SUM booking that blocks compatible concurrent use. |
| Event slot | Longer exclusive booking window such as afternoon or night. |
| Hold | Temporary reservation state that blocks required resources while payment is pending. |
| Tenant | Future SaaS isolation boundary, initially equivalent to a building/account boundary. |
| ADR | Architecture Decision Record. |
| IaC | Infrastructure as Code. |
| OPEX | Recurring operating expenditure. |
| CAPEX | Up-front/capital investment concept; exact accounting treatment is outside this repository's scope. |
