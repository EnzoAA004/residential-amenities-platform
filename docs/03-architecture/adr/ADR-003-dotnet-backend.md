# ADR-003 — Use C# / ASP.NET Core for the Backend

- **Status:** Accepted
- **Date:** 2026-09-27

## Context

The maintainer wants this project to extend beyond the usual Java/Spring Boot stack while remaining suitable for a production-style API and Azure deployment.

## Decision

Use C# with ASP.NET Core.

## Consequences

- Adds .NET experience to the portfolio.
- Aligns well with the selected Azure direction.
- Requires a learning spike for idiomatic .NET architecture, testing and security.
